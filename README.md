# Готические шашки — C# / WinForms

## Платформа

* C#
* .NET 8
* Windows Forms
* Visual Studio 2026

## Реализованные правила

* Доска 8×8.
* По 16 шашек у каждого игрока; начальная позиция — два ближайших ряда.
* Простые шашки ходят по диагонали вперёд на одну клетку.
* Дамки ходят по диагонали в обе стороны на любое число клеток.
* Простые шашки берут по диагонали вперёд и ортогонально вперёд/влево/вправо.
* Дамки берут в восьми направлениях.
* Взятие не обязательно.
* При выборе взятия применяется правило максимальной серии.
* Есть последовательные взятия.
* Превращение в дамку.
* Определение победителя.

## Запуск

Откройте `GothicCheckers.csproj` в Visual Studio и нажмите `F5`.

## Структура проекта

* GothicCheckers
* Program.cs - точка входа в программу
* GameTypes.cs - игровые объекты
* GameEngine.cs -движок игры
* ComputerPlayer.cs - компьютерный противник
* MainForm.cs - пользовательский интерфейс
* MainForm.Designer.cs - файл с описанием объектов
* GothicCheckers.csproj - информация о проекте
